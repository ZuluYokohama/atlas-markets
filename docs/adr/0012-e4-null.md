# ADR 0012 — E4 null is terminal for this protocol

**Status:** accepted  
**Date:** 2026-08-16

E4-v0 used the frozen F0 metric and the frozen E1-G trial. Every incremental rung is `UNSUPPORTED`. TCN, MoE, and neuroevolution were not started. Confirmation remains closed. A later attempt must be a new protocol ID.
