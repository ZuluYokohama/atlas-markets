# ADR 0010 — E2 detectability is not curvature

**Status:** accepted  
**Date:** 2026-08-16

A calibrated SO(2) holonomy test has type I ≈ 5% and power 0.88 at (L=8, σ=0.08, θ=0.7) against a flat connection plus transport noise. `det` has no power. This authorizes only the claim that cycle inconsistency is detectable under that null. It does not authorize market curvature, E4 inclusion, or cone language.
